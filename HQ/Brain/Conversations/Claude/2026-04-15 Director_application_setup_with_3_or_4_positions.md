## What It Is

This is an AI-powered trading agent that uses Claude to analyze markets and execute perpetual futures trades on Hyperliquid. It's a Python program that automatically trades crypto and other assets.

## What You Need to Get Started

**Prerequisites:**
- Python 3.12 or newer installed on your computer
- An Anthropic API key (for Claude)
- A Hyperliquid account with a wallet set up
- Some crypto funds in your Hyperliquid wallet (to trade with)

## Step-by-Step Setup

1. **Clone or download the repository**
   ```
   git clone https://github.com/sanketagarwal/hyperliquid-trading-agent.git
   cd hyperliquid-trading-agent
   ```

2. **Install dependencies**
   ```
   pip install hyperliquid-python-sdk anthropic python-dotenv aiohttp requests
   ```

3. **Configure your settings**
   - Copy `.env.example` to `.env`
   - Edit `.env` and add:
     - Your Anthropic API key
     - Your Hyperliquid private key (for signing trades)
     - Your Hyperliquid main wallet address
     - Which assets you want to trade (e.g., "BTC ETH SOL")
     - How often to trade (e.g., "5m" for every 5 minutes)

4. **Set up your Hyperliquid agent wallet**
   - Go to app.hyperliquid.xyz → Settings → API Wallets
   - Add your agent wallet as an authorized signer

5. **Run it**
   ```
   python3 src/main.py
   ```
