**You:** how do i connet a google folder to claude

**Claude:** Do you mean connecting a Google Drive folder so Claude can access your files? Let me search for the most up-to-date information on this.Here's how to connect Google Drive to Claude:

**In Claude.ai or the Claude app:**

1. Click the **plus sign (+)** in the chat interface below the message box.
2. Toggle the **Google Drive** connector on.
3. If it's your first time, you'll be redirected to Google to authenticate your account.

Once connected, you can search for and retrieve files from Drive directly in your conversations.

**Adding Google Docs to a Project:**

You can also add Google Docs to the Files section of a private project by clicking the "+" button, then searching for your document or pasting its URL. Note that this option is only available for private projects, not shared ones.

**A few things to keep in mind:**

- Claude can access Google Docs, Sheets, Slides, PDFs, and plain text files like .txt, .json, .csv, .html, and .md.
- Google Docs added to chats and projects sync directly from Google Drive, so you're always working with the latest version.
- If you're on a Team or Enterprise plan, an Owner or Primary Owner must enable the connector at the organization level before individual users can authenticate.

Let me know if you run into any issues getting it set up!

**Claude:** That's a great idea! Let me search for the latest info on recurring projects and how Google Drive files work with them.Good news — there are a couple of ways to set this up depending on what you mean by "recurring project."

**Option 1: Create a reusable Project (in Claude.ai)**

Projects let you create self-contained workspaces with their own chat histories and knowledge bases. You can upload documents, provide context, and have focused chats with Claude. Here's how this helps with recurring work:

- Set up your project once with custom instructions and files (including Google Docs from Drive).
- For recurring tasks, you can simply update the data and rerun the workflow — the project itself stays ready to go.
- Google Docs added to projects sync directly from Google Drive, so you're always working with the latest version.
- You can also turn AI-generated content into project knowledge, so you can reference it in future conversations.

So while projects don't automatically "run" on a schedule, they act as a persistent workspace you can return to anytime with all your context pre-loaded.

**Option 2: Scheduled Tasks in Claude Cowork (Desktop app)**

If you want something that actually runs automatically on a recurring basis, Claude Cowork lets you schedule recurring tasks — like tracking topics, organizing files, or generating status updates — at a cadence you choose. Each scheduled task runs as its own Cowork session, and you can review the results when they're ready. Just note that scheduled tasks only run while your computer is awake and the Claude Desktop app is open.
